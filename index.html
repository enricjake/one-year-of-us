An anniversary site kit · built by hand

One year.
Six ways to say it.

Six complete directions for a one-year anniversary site — same couple, same year, six very different rooms. Filled in for Nicole & Enric and long distance, using the photos she sent. Open each one, scroll it, then keep the one that sounds like you. Everything is plain HTML, CSS and JS: no build step, no dependencies, no accounts.
